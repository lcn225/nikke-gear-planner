# 胜利女神：妮姬（NIKKE）T10过载装备全局ROI清洗与升级大排队竞价算法白皮书

## 底层伤害公式与过载词条物理稀释机理

在《胜利女神：妮姬》（NIKKE）的深空高阶养成体系中，企业重塑模组（通常被称为“石头”或“重塑水晶”）作为将满级制造型T9装备蜕变为T10过载装备（Overload Gear）的唯一媒介，其清洗与装备升级决策直接决定了玩家中后期的资源配置效率与期望输出峰值 。为了避免传统粗放型攻略中依赖主观系数、模糊估算或绝对差增益所导致的致命决策偏误，必须从游戏底层的伤害结算物理公式出发，剖析各项过载属性的边缘贡献与稀释效应 。

### 妮姬底层伤害结算物理公式

妮姬的标准伤害结算在物理结构上呈现出多乘区非线性耦合的特征，其基本公式表现为 ：

$$\text{Final Damage} = \text{Base Damage} \times \text{Major Modifiers} \times \text{Attribute Bonus} \times \text{Charge Multiplier} \times \text{Other Modifiers}$$

其中，直接决定过载属性边缘稀释的核心子乘区定义如下 ：

$$\text{Base Damage} = \left( \text{Character Base ATK} \times \left(1 + \sum \text{ATK Buffs}\right) - \text{Monster DEF} \right) \times \text{Skill Multiplier}$$

$$\text{Major Modifiers} = 1 + \text{Crit Damage Bonus} + \text{Core Hit Bonus} + \text{Distance Bonus} + \text{Full Burst Bonus}$$

$$\text{Attribute Bonus} = 1.1 + E_{\text{OL\_Superior\_Code}}$$

### 攻击力与暴击类词条的加法稀释效应

攻击力词条在实战中会面临严重的“主动Buff加法稀释” 。在标准的高阶战斗环境（如单人突袭或联合战役）中，丽塔、皇冠、娜嘉等顶级辅助妮姬会为场上主输出（Main DPS）提供常态化在 $100\%$ 至 $150\%$ 之间的主动攻击力百分比提升 。由于过载装备提供的“攻击力增加”词条（单槽最大值为 Tier 15 的 $14.63\%$）与这些主动战斗 Buff 在基础伤害乘区内呈**加法 Summated 关系** ，其实际相对提升率会随着辅助强度的增加而急剧退化。例如，当场上已存在 $120\%$ 的主动攻击 Buff 时，一条 $14.63\%$ 的过载攻击力词条带来的实际输出增幅仅为 $14.63\% / (1 + 1.2) \approx 6.65\%$ 。

暴击率与暴击伤害词条的退化则更为剧烈 。主要乘区修正项（Major Modifiers）将暴击加成、核心打击（Core Hit，基础加成为 $+100\%$） 、距离加成（$+30\%$） 以及全爆发状态（Full Burst，基础加成为 $+50\%$） 完全归入同一个加法 bracket 中 。由于妮姬的基础暴击伤害仅有 $50\%$ ，且在绝大多数高阶战斗中，输出手均能稳定命中敌方弱点（核心打击）并在全爆发期间宣泄火力，这导致主要乘区的基数常态化处于 $1.0 + 1.0 + 0.3 + 0.5 = 2.8$ 极高水平 。此时，过载属性中提供的暴击伤害（单槽最大 $22.15\%$） 甚至只能在触发暴击时提供 $22.15\% / 2.8 \approx 7.91\%$ 的微幅稀释提升 。在乘以暴击率期望后，其真实边缘收益将进一步萎缩至不足 $1\%$，在统计学上近乎可以忽略不计 。

### 属性克制（优越代码）的独立乘区物理优势

与攻击力和暴击类属性不同，“优越代码伤害增加”词条作为针对克制属性敌人的专属加成，在伤害公式中享有完全**独立相乘**的乘区地位 。由于基础属性克制加成仅为 $10\%$ ($0.1$) ，该乘区的基础分量为 $1.1$。过载装备提供的单槽最大 $26.36\%$ 优越代码加成 在该乘区进行加法堆叠后，其相对提升率在克制环境下高达 $26.36\% / 1.1 \approx 23.96\%$ 。这种不与任何战场主动 Buff 发生干涉的物理独立性，确立了优越代码词条在高难度突袭战克制环境下的绝对支配地位，其抗稀释能力在定量分析中被评估为全词条池最高。

### 词条槽位抽取概率与无放回超几何选择机制

过载装备在生成或使用石头进行属性重构（Change Effects）时，其第一、二、三槽位的激活概率分别为 $100\%$、$50\%$ 和 $30\%$ 。

| **槽位编号** | **天然激活概率** | **生成词条池特性**              |
| -------- | ---------- | ------------------------ |
| **第一槽位** | $100\%$    | 锁定基准线，重置时无条件激活并随机分配新属性   |
| **第二槽位** | $50\%$     | 概率开启，若未开启则洗练时无法生成任何属性    |
| **第三槽位** | $30\%$     | 极难开启，是决定装备是否达到三有效词条的黄金瓶颈 |

由于过载装备存在严苛的“同类词条互斥原则”，即在同一件装备上绝对不可能出现两条或以上完全相同的词条（例如，一件装备无法同时拥有两条攻击力词条） ，因此随着玩家锁定某一极品属性，剩余槽位在重新进行洗练时，该属性会被永久剔除出候选池。这种机制使得后续词条的生成过程属于典型的“无放回超几何选择” 。这一物理限制在锁定词条时会产生双重效应：它虽然提升了在剩余激活槽位中洗出其他目标词条的概率，但代价是后续单次洗练的石头消耗成本呈几何倍数暴增，并在仅剩第三槽位未锁定时面临由于激活概率低（$30\%$）和目标池缩小所带来的期望成本悬崖 。

## 基于几何分布的洗练成本模型

每一次消耗企业重塑模组进行词条洗练的操作，在数学上均可建模为一次独立的伯努利试验（Bernoulli Trial）。因此，洗练直至获得目标状态所需的试验次数 $N$ 严格服从几何分布（Geometric Distribution） ：

$$N \sim \text{Geo}(P_{\text{success}})$$

根据几何分布的数学期望，首次成功所需的平均重塑模组消耗量为 ：

$$\mathbb{E}[N] = \frac{1}{P_{\text{success}}}$$

### 无锁洗练（0 Locks）成本推导

在完全无锁状态下，每次洗词条固定消耗 $1$ 颗重塑模组 。设目标词条池（属于该妮姬的有效目标属性集合）大小为 $M$ ，总候选词条池大小为 $9$ 种 。我们必须首先计算不同激活槽位组合下的超几何选择概率。
设激活槽位总数 $A \in \{1, 2, 3\}$。根据第一、二、三槽位的开启概率独立性，激活槽位数的分布规律呈现为 ：

$$P(A = 1) = 1.0 \times (1 - 0.5) \times (1 - 0.3) = 0.35$$

$$P(A = 2) = 1.0 \times 0.5 \times (1 - 0.3) + 1.0 \times (1 - 0.5) \times 0.3 = 0.50$$

$$P(A = 3) = 1.0 \times 0.5 \times 0.3 = 0.15$$

在给定激活槽位数 $a$ 的情况下，洗出 $x$ 个有效目标词条的条件概率服从超几何分布 ：

$$P(X = x \mid A = a) = \frac{\binom{M}{x} \binom{9 - M}{a - x}}{\binom{9}{a}}$$

若装备当前已持有 $e$ 个有效词条（$e < 3$），欲通过一次无锁重构使有效词条数至少增加到 $e+1$ 的单次成功率 $P_{\text{success\_0}}$ 计算为：

$$P_{\text{success\_0}} = \sum_{a=1}^{3} P(A = a) \sum_{x=e+1}^{a} \frac{\binom{M}{x} \binom{9 - M}{a - x}}{\binom{9}{a}}$$

对应的几何期望成本为 ：

$$\mathbb{E}[C_{\text{wash\_0}}] = \frac{1}{P_{\text{success\_0}}}$$

### 锁一洗二（1 Lock）成本推导

当玩家锁定一个具有高极品数值的有效词条后，锁定动作将消耗 $2$ 颗模组，且此后的每次洗练成本永久提升至 $2$ 颗 。此时，被锁定的词条槽位被剔除，可变随机槽位仅剩剩余的两个槽位。剩余两个槽位的激活状态呈现出以下分布 ：

- 剩余 $0$ 个激活槽位（槽位 2 和 3 均未开启）：概率 $P(A_{\text{rem}} = 0) = 0.5 \times 0.7 = 0.35$ ；

- 剩余 $1$ 个激活槽位（仅开启槽位 2 或仅开启槽位 3）：概率 $P(A_{\text{rem}} = 1) = 0.5 \times 0.7 + 0.5 \times 0.3 = 0.50$ ；

- 剩余 $2$ 个激活槽位（槽位 2 和 3 均开启）：概率 $P(A_{\text{rem}} = 2) = 0.5 \times 0.3 = 0.15$ 。

由于已有 1 条目标词条被锁定，词条总池容量收缩至 $8$，剩余有效目标数变为 $M - 1$ 。在此状态下，洗出至少 $1$ 条新有效目标词条的单次成功率 $P_{\text{success\_1}}$ 为：

$$P_{\text{success\_1}} = \sum_{a_{\text{rem}}=1}^{2} P(A_{\text{rem}} = a_{\text{rem}}) \left( 1 - \frac{\binom{9 - M}{a_{\text{rem}}}}{\binom{8}{a_{\text{rem}}}} \right)$$

洗出下一个有效词条的几何期望总成本（含锁词动作本身的一次性石头消耗）推导为 ：

$$\mathbb{E}[C_{\text{wash\_1}}] = 2 \text{ (锁定单次消耗)} + \frac{2}{P_{\text{success\_1}}} \text{ (期望洗练消耗)}$$

### 锁二洗一（2 Locks）成本推导

锁定两个极品词条需要支付一次性锁词成本 $3$ 颗，且后续每次洗词条消耗永久固定为 $3$ 颗 。此时仅剩唯一的槽位 3 参与随机洗练，该槽位能够提供新词条的概率上限被槽位 3 自身的激活概率（$30\%$）锁死 。
剩余候选词条池收缩至 $7$，剩余有效目标数为 $M - 2$ 。在此状态下洗出最后一条目标属性的单次成功率 $P_{\text{success\_2}}$ 为：

$$P_{\text{success\_2}} = 0.3 \times \frac{M - 2}{7}$$

其期望总成本为 ：

$$\mathbb{E}[C_{\text{wash\_2}}] = 3 \text{ (锁定单次消耗)} + \frac{3}{P_{\text{success\_2}}}$$

### 渐进式数值洗练（数值提纯）成本模型

对于已经拥有 $k$（$1 \le k \le 3$）条有效词条但数值偏低（低于期望中的高档位 Tier 11+）的装备，其数值提纯策略绝非盲目重洗，而是需要采用“渐进式锁定清洗（Progressive Locking Wash）”方案 。
根据妮姬的数值档位概率分布事实，单个槽位随机洗出 Tier 11 或更高档位（综合出现概率仅为 $15\%$，即 $P_{\text{high}} = 0.15$）的极品属性是极难发生的 。
渐进式提纯的物理步骤表现为：首先在不加锁的情况下洗练所有槽位，直到其中任意一条达到 Tier 11+；然后锁定该条，继续洗练剩余槽位，直至产生第二条 Tier 11+；最后双锁，单洗第三槽位直至完美 。
根据几何分布累加，将拥有不同有效词条数 $k$ 的装备彻底提纯至全员 Tier 11+ 的渐进式期望总成本 $C_{\text{value\_pure}}(k)$ 计算如下表所示 ：

| **有效词条数 k** | **数值洗练物理跃迁路径及锁定代价**                                                                                                                   | **期望消耗模组数（石头） E[C]** |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| **$k = 1$** | 无需锁定，直接单槽重洗。单次成功率 $15\%$，每次洗练成本 $1$ 颗 。                                                                                               | **$6.67$ 颗**         |
| **$k = 2$** | 洗双槽中至少一槽达到 Tier 11+（成功率 $27.75\%$，每次 $1$ 颗） $\to$ 锁定该槽（付 $2$ 颗） $\to$ 单洗最后一槽达到 Tier 11+（成功率 $15\%$, 每次 $2$ 颗） 。                       | **$18.93$ 颗**        |
| **$k = 3$** | 洗三槽中至少一槽达到 Tier 11+（成功率 $38.59\%$，每次 $1$ 颗） $\to$ 锁一洗二（成功率 $27.75\%$，每次 $2$ 颗，含锁词 $2$ 颗） $\to$ 锁二洗一（成功率 $15\%$, 每次 $3$ 颗，含锁词 $3$ 颗） 。 | **$34.79$ 颗**        |

异常干涉锁定系统的未来演化：随着近期游戏在异常拦截战（Anomaly Interception）中引入单次消耗性锁词道具 ，这一渐进式锁定提纯的石头消耗在短期内得到了方差上的平抑。然而，鉴于该道具属于“单次洗练后即行失效并需重新涂抹”的非永久锁定物理性质 ，其期望成本分析在长期视角下仍旧与上述基于重塑模组的渐进式锁定期望曲线完全重合，因而并不改变本算法的长期 ROI 排队顺序。

## 装备升级的影子价格与等效换算

装备从非过载状态向过载状态转化，其本质是一次基础属性的大幅跃升与过载词条的无条件附赠 。这一物理升级需要将 T9 企业制造型装备强化至 Lv 5 。对于过载装备固有升级（Lv 0 $\to$ Lv 5）的评估，其痛点在于强化过程仅消耗信用点（Credits）与装备强化经验（EXP） ，而不消耗重塑石头。为了将“洗练词条”与“装备等级提升”拉通至同一个 ROI 榜单进行竞价排队，必须引入宏观经济学中的影子价格（Shadow Pricing）换算体系，消除资源跨度壁垒 。

### 信用点到重塑模组的影子价格系数 $\lambda$

在服务器后期（同步器等级越过 200 级瓶颈后），信用点与企业重塑模组在每日获取途径（异常战、突袭、日常产出）中的稀缺度之比构成了客观的资源市场影子汇率 。在全勤活跃环境下，两者的相对价值均衡系数定义为：

$$\lambda = \frac{1.5 \times 10^6 \text{ Credits}}{1 \text{ Custom Module}}$$

以此影子价格为基准，强化一整件 T10 装备至满级所需的 $2.4\text{M}$ 信用点 即可被完美折算为等效的石头成本，完成两类不同养成动作在同一数轴上的物理对齐 。各强化阶段的详细影子折算数据如下表所示 ：

### 面板属性的线性跃迁规律

制造型装备在进行过载和升级时，其增加的攻击力、防御力和生命值面板完全服从线性增长特征 。然而，装备部位不同，其提供的增益类型存在严苛的物理壁垒 ：

- **头部装备（Helmet）**：升级的核心物理增益全部集中于“攻击力（ATK）”，是主输出（DPS）角色最优先强化的第一核心部位 ；

- **手部装备（Gloves）**：升级提供次要的攻击力增益，同时提供少量的生命值，是输出角色的第二核心部位 ；

- **身体装备（Chest）**：升级几乎不提供任何攻击力，而是提供海量的生命值（HP）和物理防御（DEF）。该部位在 DPS 角色身上升级的边缘收益极低，但在依赖自身最大生命值上限进行治疗系数结算的辅助或盾职业（如布兰儿、玛奇玛、马克西玛）身上，其 ROI 权重会发生偏转 ；

- **足部装备（Boots）**：升级仅提供微量生命值与防御力，对任何流派的输出拉升作用均几乎为零，属于极其昂贵且低效的虚标战力陷阱，常态下升级 ROI 被判定为全强化动作最低 。

根据满载同步器下后期角色的裸面板与基准强化属性，当前角色的总平均面板攻击力大约稳定在 $35,000$。在此基础之上，升级头部和手部装备可获得如下线性绝对物理面板增幅 ：

- 头部装备（Helmet）每级强化增加攻击力：$\Delta ATK_{\text{head}} = 900$ 点 ；

- 手部装备（Gloves）每级强化增加攻击力：$\Delta ATK_{\text{hand}} = 440$ 点 。

## 乘区相对提升率收益函数的定量化构建

为了彻底规避定性分析中“主观打分、权重分配、绝对差额增益（忽略基数）”等不具备数学严谨性的做法，本白皮书算法确立了累乘相对提升率（Relative Multiplicative Gain）作为收益函数的唯一衡量指标。该指标的物理意义是：**特定的洗练或升级操作完成后，角色在标准战斗场景下的期望输出（DPS）相较于当前状态的绝对百分比增幅** 。

设角色的整体伤害模型由五个相互独立的物理乘区进行累乘求积得到 ：

$$\mathcal{F} = \mathcal{M}_{\text{ATK}} \times \mathcal{M}_{\text{Ele}} \times \mathcal{M}_{\text{Ammo}} \times \mathcal{M}_{\text{CS}} \times \mathcal{M}_{\text{Other}}$$

因此，操作 $S \to S'$ 引起的整体收益函数为 ：

$$B(S \to S') = \frac{\mathcal{F}(S')}{\mathcal{F}(S)} - 1$$

由于各乘区物理意义各异，其分量收益函数和边缘增幅计算公式分别进行如下定量化构建：

### 1. 攻击力乘区分量 $\mathcal{M}_{\text{ATK}}$

由于主动攻击力 Buff 的强稀释作用 ，引入战场基准乘数项 $D_{\text{buff}}$（在带双神级辅助皇冠和丽塔的标准推图/突袭环境中，基准主动 ATK Buff 之和常态化达到 $100\%$ 以上，因此将该基准值设为常数 $2.0$） 。
设当前装备上已有的过载攻击力百分比总和为 $A_{\text{OL}}$（四件套极限上限为 $58.52\%$）。

对于通过洗练增加攻击力词条或提纯攻击数值的操作，其攻击力乘区增幅函数为 ：

$$\mathcal{M}_{\text{ATK}}(A_{\text{OL}} \to A_{\text{OL}} + \Delta A_{\text{OL}}) = \frac{2.0 + A_{\text{OL}} + \Delta A_{\text{OL}}}{2.0 + A_{\text{OL}}}$$

对于升级头部或手部装备的操作，由于其增加的是固定物理面板攻击力，其增幅直接乘算战斗内攻击加成，其增幅函数表现为 ：

$$\mathcal{M}_{\text{ATK\_upgrade}}(v \to v+1) = \frac{ATK_{\text{current}} + \Delta ATK_{\text{part}}}{ATK_{\text{current}}}$$

其中，根据前述物理常数，$\Delta ATK_{\text{head}} = 900$，$\Delta ATK_{\text{hand}} = 440$ 。

### 2. 优越代码属性克制乘区分量 $\mathcal{M}_{\text{Ele}}$

克制环境下的基础加成比例为常数 $1.1$（即 $+10\%$ 额外属性克制伤害） 。
设当前装备上已有的过载优越代码百分比总和为 $E_{\text{OL}}$。
增加或提升优越代码词条数值后，该乘区的收益函数为 ：

$$\mathcal{M}_{\text{Ele}}(E_{\text{OL}} \to E_{\text{OL}} + \Delta E_{\text{OL}}) = \frac{1.1 + E_{\text{OL}} + \Delta E_{\text{OL}}}{1.1 + E_{\text{OL}}}$$

### 3. 最大装弹数乘区分量 $\mathcal{M}_{\text{Ammo}}$

装弹数并不是一个简单的加法或乘法输出参数，而是通过重塑角色的“发射-换弹”循环周期，来改善角色在战场上的持续输出时间占空比（Duty Cycle） 。
设角色基础弹夹容量为 $C_{\text{base}}$，当前装备过载装弹百分比之和为 $Ammo_{\text{OL}}$，则实际物理弹夹容量为 $C = C_{\text{base}} \times (1 + Ammo_{\text{OL}})$ 。
设妮姬的物理射速为 $F$（发/秒），单次换弹硬直时间为 $R$（秒） 。则持续输出时间占空比为 ：

$$D(Ammo_{\text{OL}}) = \frac{\frac{C}{F}}{\frac{C}{F} + R} = \frac{C}{C + F \cdot R}$$

由此构建的装弹数相对收益分量函数为：

$$\mathcal{M}_{\text{Ammo}}(Ammo_{\text{OL}} \to Ammo_{\text{OL}} + \Delta Ammo_{\text{OL}}) = \frac{C_{\text{base}}(1 + Ammo_{\text{OL}} + \Delta Ammo_{\text{OL}})}{C_{\text{base}}(1 + Ammo_{\text{OL}} + \Delta Ammo_{\text{OL}}) + F \cdot R} \times \frac{C_{\text{base}}(1 + Ammo_{\text{OL}}) + F \cdot R}{C_{\text{base}}(1 + Ammo_{\text{OL}})}$$

对于某些具有极端特殊反向被动机制的角色（例如**阿妮斯：闪耀夏日**，其核心杀伤机制极度依赖“写在弹夹最后一发子弹上的爆发性闪电被动伤害”） ，增加弹夹量会灾难性地延长其打空弹夹的耗时，导致核心爆发频率大幅度退化 。为此，算法对此类特定妮姬引入反向惩罚收益函数 ：

$$\mathcal{M}_{\text{Ammo\_Anis}}(Ammo_{\text{OL}} \to Ammo_{\text{OL}} + \Delta Ammo_{\text{OL}}) = \frac{1.0}{1.0 + 10.0 \times \Delta Ammo_{\text{OL}}}$$

该函数会赋予弹夹增加一个陡峭的负收益，彻底杜绝其在全局排队中胜出的可能性。

### 4. 蓄力速度乘区分量 $\mathcal{M}_{\text{CS}}$

对于以爱丽丝（Alice）**和**小红帽（Red Hood）为首的顶级狙击型（SR）输出手，蓄力速度的边缘价值存在物理临界突变点（秒蓄门槛） 。
以爱丽丝为例，在大招期间其自身技能提供高达 $91.82\%$ 的蓄力速度加成 。由于游戏引擎的硬动画帧率限制，蓄力速度总和达到 $99.52\%$ 时即判定为瞬时完成蓄力（秒蓄） 。这意味着爱丽丝跨越物理瓶颈所需的过载外部补偿总额为 ：

$$\Delta_{\text{instant}} = 99.52\% - 91.82\% = 7.7\%$$

同理，小红帽实现秒蓄所需的额外补偿门槛大约为 $10.0\%$ 。
当过载提供的蓄力速度总和 $CS_{\text{OL}} < \Delta_{\text{instant}}$ 时，单发时间为蓄力时间与硬直动画时间（$0.35$ 秒）之和：$1.5 \times (1.0 - 0.9182 - CS_{\text{OL}}) + 0.35 = 0.4727 - 1.5 \times CS_{\text{OL}}$ 秒 ；
当 $CS_{\text{OL}} \ge \Delta_{\text{instant}}$ 时，蓄力硬直彻底消失，射击时间直接缩短至纯硬直动画极限量：$0.35$ 秒 。
因此，其非连续射速乘区增幅函数表现为非线性阶梯函数 ：

$$\mathcal{M}_{\text{CS}}(CS_{\text{OL}}) = \frac{1.0}{0.4727 - 1.5 \times \min(0.077, CS_{\text{OL}})}$$

该公式表明，当蓄速补偿总和一旦跨过 $7.7\%$（爱丽丝）或 $10\%$（小红帽）的物理临界点后，更进一步增加蓄速词条的相对收益会瞬间归零，对应的边际 ROI 将遭遇物理断崖 。

## 全局ROI竞价与大排队排位机制

全局竞价大排队算法 $\mathcal{A}_{\text{ROI}}$ 的核心设计逻辑在于，将完全处于不同物理维度的三种操作：“白板开光”（指通过消耗 1 石头将 T9M 面板升级为 T10 过载并抽取初始词条） 、“洗种类”（调整已有过载装备的词条并争取开辟新槽位） 、“洗数值”（保持词条种类，通过锁定将已有词条的数值纯化至 Tier 11+） 、以及“装备固有等级强化（消耗信用点升级）” 整合在同一个竞价公式中：

$$\text{ROI}(i, g, a) = \frac{\Delta B(i, g, a)}{\Delta C(i, g, a)}$$

在该竞价公式中，算法对账号下所有妮姬 $i$ 的每一件装备 $g$ 执行全操作空间 $a$ 的遍历计算，并根据绝对客观的投资回报率进行降序大排队，从而完美解决了白板开光与数值提纯在决策上的客观竞争优势问题 。

### 白板开光与数值提纯的博弈结果分析

许多玩家在没有算法指导时，极易陷入将极少数一两件装备洗练到完美极致、而其他二队主力的装备保持在白板甚至未过载状态的误区 。算法在数学上对这两类操作进行了清晰的价值分层 ：

- **白板开光（0 词条 $\to$ 1 词条）的物理博弈特征**：在无锁状态下，洗出第一个有用词条的概率在超几何分布与三槽激活概率耦合下高达近 $78\%$。其期望消耗重塑模组数量仅为 $1.28$ 颗 。该操作通常能直接解锁一条在战场上提供大约 $5\%$ 到 $8\%$ 输出增幅的攻击力或弹夹词条 ，其在算法中的边际竞价因子为：

$$\text{ROI}_{\text{open}} = \frac{0.06}{1.28} \approx 0.0469$$

- **高阶数值提纯的物理博弈特征**：要将一个已有 3 有效词条的装备全员洗练至 Tier 11+（数值提纯），其期望模组消耗高达惊人的 $34.79$ 颗 。然而，词条数值从普通的 Tier 4 提升到极品的 Tier 12，给角色带来的真实实战输出乘区提升往往仅有微弱的 $2\%$ 到 $3.5\%$ 。此时，其边际竞价因子收缩为：

$$\text{ROI}_{\text{purify}} = \frac{0.025}{34.79} \approx 0.0007$$

两者的投资回报率相差了近 **67 倍**！因此，大排队排位机制会无条件地迫使玩家将宝贵的重塑模组优先铺平到所有核心队伍的“白板过载开光”以及“洗出两词条”阶段 ，直到全队基本面完全铺满，高阶提纯的极低 ROI 才会由于无其他可升级动作而慢慢爬升至队列前列，彻底规避了局部过度投资的经济学毁灭 。

def get_hypergeometric_prob(a, m, total=9):
    """计算无放回抽取条件下的超几何概率分布"""
    from scipy.special import comb
    probs = {}
    for x in range(0, min(a, m) + 1):
        if a - x <= total - m:
            probs[x] = comb(m, x) * comb(total - m, a - x) / comb(total, a)
        else:
            probs[x] = 0.0
    return probs

def evaluate_wash_stats_expected_cost(current_targets, all_targets):
    """核心算法：基于几何分布，推导开辟槽位与洗种类所需的期望石头成本"""
    m = len(all_targets)
    e = len(current_targets)

    if e == 0:
        # 完全无锁状态下洗出第一个目标词条的概率
        p_success = 0.0
        for a, p_a in [(1, 0.35), (2, 0.50), (3, 0.15)]:
            probs = get_hypergeometric_prob(a, m, total=9)
            p_success += p_a * (1.0 - probs.get(0, 0.0))
        return 1.0 / p_success if p_success > 0 else float('inf')

    elif e == 1:
        # 锁一洗二状态下洗出第二个目标词条的期望成本
        p_success = 0.0
        for a_rem, p_a in [(1, 0.50), (2, 0.15)]:
            probs = get_hypergeometric_prob(a_rem, m - 1, total=8)
            p_success += p_a * (1.0 - probs.get(0, 0.0))
        return 2.0 + (2.0 / p_success) if p_success > 0 else float('inf')

    elif e == 2:
        # 锁二洗三状态下洗出第三个目标词条的期望成本
        p_success = 0.30 * ((m - 2) / 7.0)
        return 3.0 + (3.0 / p_success) if p_success > 0 else float('inf')

    return float('inf')
