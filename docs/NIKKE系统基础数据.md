# NIKKE 装备过载洗练系统：底层物理数据与伤害乘区规格书

## 一、 伤害公式与乘区稀释事实 (Damage Formula)

根据测试结果与大佬提供的解包数据，游戏内的最终伤害输出严格遵循以下累乘乘区：

$$\text{最终伤害} = \text{基础伤害区} \times \text{补正区} \times \text{属性克制增伤区} \times \text{蓄力增伤区} \times \text{额外增伤区} \times \text{易伤区}$$

### 1.1 各核心乘区客观事实

1. **基础伤害区**：
   
   $$\text{基础伤害区} = (\text{角色基础攻击} \times \text{攻击力buff和} - \text{怪物防御力}) \times \text{武器或技能倍率}$$
   
   - **防御力加减法影响**：由于防御力是以直接相减的减法形式参与运算，导致处于该乘区内部的“攻击力 Buff”战略收益极高。

2. **补正区（加算灾难乘区）**：
   
   $$\text{补正区} = (1 + \text{暴击伤害} + \text{弱点补正} + \text{距离补正} + \text{全爆裂补正})$$
   
   - **稀释事实**：弱点补正($1.0$)、距离补正($0.3$)与全爆裂补正($0.5$)的基础之和高达 **$1.8$**。而暴击伤害的初始基础只有 **$0.5$**。由于这四者在同一区域内执行**加算**，导致暴击类增伤（暴击率、暴击伤害）在实战中受到严重稀释，初始收益极其低下，同数值下被处于基础区的“攻击力提高”全方位立体式爆杀。

3. **属性克制增伤区**：
   
   - 基准事实：在面对克制属性敌人时，基础属性克制初始值恒等于 **$1.1$**（部分特定环境存在特殊情况）。过载装备中的“优越代码增伤”在此区域执行加算。

4. **蓄力增伤区**：
   
   - 基础为 $2.5$ 或 $3.5$，不同角色情况不同。过载词条中的“蓄力伤害”在此区域加算。

5. **额外增伤区**：
   
   $$\text{额外增伤区} = (1 + \text{部位破坏} + \text{其他增伤(例如海伦技能)})$$

6. **易伤区**：
   
   - 多易伤叠加效果推测为加算。

## 二、 槽位判定机制与全量词条池概率 (Slot & Pool Mechanisms)

无论是头、身、手、足哪个部位，过载开光时面对的效果池完全一致，均包含全量 9 种词条。

### 2.1 槽位出现率

- **1号位（首栏）**：$100\%$ 概率赋予效果。

- **2号位（次栏）**：$50\%$ 概率赋予效果，另外 $50\%$ 概率表现为空白（未开光）。

- **3号位（末栏）**：$30\%$ 概率赋予效果，另外 $70\%$ 概率表现为空白（未开光）。

### 2.2 独立出词率

当位置判定有词条时，各词条出现的抽取概率各自独立：

- **暴击率、防御力、攻击力、优越代码增伤**：各占 **$10\%$** 出现概率。

- **蓄力速度、命中率、蓄力伤害、暴击伤害、最大装弹数**：各占 **$12\%$** 出现概率。

- *注：同一件装备上绝对无法出现两个相同的词条种类。当玩家锁定 $M$ 个词条后，剩余未占用的词条概率分母需扣除已被锁定的种类。*

## 三、 锁词洗练的追加门票与滚动刚性成本 (Locking Cost Scale)

游戏内锁词洗练的自定义模块（石头）损耗严格区分为“锁定动作瞬时门票”与“重置面板滚动费”：

### 3.1 瞬时门票费用（点击锁定扣除，一次性叠加）

- **从不锁 ➡️ 锁定第 1 个词条**：追加扣除 = **2 颗石头**。

- **从锁 1 ➡️ 锁定第 2 个词条**：追加扣除 = **3 颗石头**。

- *注：若连续锁定两条，累积门票成本为 2 + 3 = 5 颗石头。*

### 3.2 滚动洗练费用（点击重置消耗，单次滚动）

- **当前锁定 0 个词条**：每次重置效果/数值消耗 = **1 颗石头**。

- **当前锁定 1 个词条**：每次重置效果/数值消耗 = **2 颗石头**。

- **当前锁定 2 个词条**：每次重置效果/数值消耗 = **3 颗石头**。

### 3.3 重新设定数值 (Reroll Value) 的刚性石头消耗事实

“重新设定数值”是一个独立的功能按钮。点击后，装备上现有的所有词条种类（Effects）100% 被锁定继承，绝对不会改变或消失；但所有条目对应的等级（1~15级）和效果百分比将全量重新随机生成。

单次点击【重新设定数值】的自定义模块（石头）消耗，与当前装备已锁定的词条数量执行完全相同的刚性绑定：

* **当前锁定 0 个词条**：点击一次“重新设定数值” 消耗 = **1 颗石头**。
* **当前锁定 1 个词条**：点击一次“重新设定数值” 消耗 = **2 颗石头**。
* **当前锁定 2 个词条**：点击一次“重新设定数值” 消耗 = **3 颗石头**。

## 四、 等差档位与 1-15 级效果百分比事实 (Tier Distribution)

词条生成或数值重设时，其等级处于 1 $\sim$ 15 级的三个固定加权轮盘区间内，概率严重偏向低级：

- **1级 $\sim$ 5级**：整体出现概率为 **$60\%$**（单级等概率为 $12\%$）。

- **6级 $\sim$ 9级**：整体出现概率为 **$35\%$**（单级等概率为 $7\%$（注：9级占7%））。

- **11级 $\sim$ 15级 (蓝/黑词门槛)**：整体出现概率为 **$5\%$**（单级等概率为 $1\%$）。
